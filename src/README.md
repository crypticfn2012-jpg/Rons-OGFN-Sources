## Random Resources

A small collection of files and assets for modding and related use cases.

### Downloads

- **`tournamenthud.dll`**  
  Inject this into your game to display tournament points.

- **`arenahud.dll`**  
  Inject this into your game to display arena points.

- **`Hero_`**  
  A base hero for modding 9.10. Useful as a starting point for skins, then you can fill in the rest.

- **`proper_fn_skeleton_1`**  
  FN skeleton for idle animations.
